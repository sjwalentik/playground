# Text-to-Speech UI

A simple text-to-speech interface using the Web Speech API.

## Features
- Convert any text to spoken audio
- Select from available system voices
- Adjust speech rate and pitch
- Pause/resume and stop functionality
- Responsive design

## How to Use
1. Open `index.html` in a modern browser
2. Enter your text in the input area
3. Select a voice from the dropdown
4. Adjust rate (0.5x-2x) and pitch (0.5-2x)
5. Click "Speak" to hear it!

## Browser Support
Works in all modern browsers with Web Speech API support (Chrome, Firefox, Edge, Safari).
