# Speech-to-Text UI

A speech-to-text interface using the Web Speech API (Web Speech Recognition).

## Features
- Real-time speech recognition
- Live transcription as you speak
- Copy to clipboard functionality
- Modern gradient design
- Error handling for common issues
- Responsive design

## How to Use
1. Open `index.html` in a modern browser (Chrome, Edge, or Safari)
2. Click **"🎙️ Start Listening"**
3. Allow microphone access when prompted
4. Speak clearly into your microphone
5. Watch your speech transcribe in real-time!
6. Click **"⏹️ Stop Listening"** when done
7. Use **"📋 Copy Text"** to copy your transcription to clipboard

## Browser Support
Works best in Chrome, Edge, or Safari which have the best support for the `webkitSpeechRecognition` API.

## Notes
- Requires microphone access
- Works best in a quiet environment
- Transcription accuracy depends on clear speech
